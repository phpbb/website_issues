# phpBB.com website issues

The issue tracker for the phpBB.com websites themselves — [www.phpbb.com](https://www.phpbb.com),
[area51.phpbb.com](https://area51.phpbb.com) and related subdomains.

## What belongs here

Anything wrong with the sites: broken links and pages, layout and display problems, incorrect or
out-of-date content, search, downloads and sign-in. Feature requests and suggestions for the
sites are welcome too.

[Open an issue &rsaquo;](https://github.com/phpbb/website_issues/issues/new/choose)

## What belongs elsewhere

| | |
| --- | --- |
| Bugs in the phpBB software | [tracker.phpbb.com](https://tracker.phpbb.com/browse/PHPBB3) |
| The User Guide and documentation | [phpbb/documentation](https://github.com/phpbb/documentation) |
| The customisation database | [tracker.phpbb.com](https://tracker.phpbb.com/browse/CUSTDB) |
| Individual extensions and styles | their authors, via the customisation database |
| Help running your own board | the [support forums](https://www.phpbb.com/community/viewforum.php?f=661) |

A security problem with the sites is not a normal issue — see [SECURITY.md](SECURITY.md) and
report it privately.
